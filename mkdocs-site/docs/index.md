# Сравнение генераторов статических сайтов

Данный сайт является тестовым стендом для выполнения задания T1.
На одинаковом содержимом сопоставляются MkDocs Material, Sphinx с MyST,
Pelican и Quarto.

## Цель эксперимента

Целью является выбор генератора для публикации результатов вычислительных
экспериментов: с формулами, рисунками, таблицами, интерактивными графиками,
ноутбуками и библиографией.

## Проверка русскоязычного поиска

В этом тексте намеренно используются разные формы слов:

- эксперимент;
- эксперимента;
- эксперименты;
- экспериментальный;
- измерение;
- измерений.

Введите эти слова в строку поиска в верхней части сайта и зафиксируйте,
какие формы были найдены.
